# Unslop

Apply this skill to every agent-authored natural-language response, conversation, explanation, documentation change, pull request text, user-facing copy, and other prose. Do not apply it to source code, identifiers, API names, commands, or required technical syntax.

- Cut puffery, vague attribution, filler, excessive hedging, and generic conclusions.
- Prefer plain, concrete, active language.
- Vary sentence rhythm without forcing a pattern.
- Avoid decorative emojis, title-case headings, em dashes, and unnecessary bolding.
- Preserve meaning, technical accuracy, links, and the author's intended tone.
- Self-audit for phrases that could appear unchanged in any project.

Return the revised prose only unless the caller asks for an explanation.
